## 📖 درباره پروژه

Smart Planner یک اپلیکیشن تحت وب کاملاً آفلاین و Progressive Web App (PWA) است که به شما کمک می‌کند:

- 🎯 پروژه‌ها و کارهای خود را سازماندهی کنید
- 📊 بهره‌وری خود را تحلیل و بهبود دهید
- 🔥 عادت‌های روزانه خود را پیگیری کنید
- 📝 ایده‌ها و یادداشت‌های خود را مدیریت کنید
- 🍅 با تکنیک Pomodoro تمرکز خود را افزایش دهید
- 🏆 با کسب دستاوردها انگیزه بگیرید

---

## ✨ ویژگی‌ها

### 📊 داشبورد هوشمند
- **۱۰ ویجت قابل شخصی‌سازی** - چیدمان دلخواه خود را بسازید
- **نمره بهره‌وری روزانه** (۰-۱۰۰) بر اساس کارها، تمرکز و استریک
- **Drag & Drop** برای تغییر ترتیب ویجت‌ها
- **ذخیره چیدمان** در LocalStorage

### 📁 مدیریت پروژه‌ها
- ایجاد و ویرایش پروژه‌ها با رنگ‌بندی
- پیشرفت هر پروژه با Progress Bar
- آمار تفصیلی هر پروژه
- جستجو و فیلتر

### ✅ مدیریت کارها
- **دو نمای مختلف:**
  - **لیست (List)** - با فیلترهای پیشرفته
  - **کانبان (Kanban)** - با Drag & Drop در ۳ ستون (در انتظار / در حال انجام / انجام شده)
- **زیرتسک (Subtasks)** با ویرایش درجا
- **تگ‌ها (Tags)** با فیلتر سریع
- **تکرار کار (Recurring)** - روزانه / هفتگی / ماهانه
- **اولویت‌بندی** - کم / متوسط / بالا
- **تاریخ و ساعت** انجام
- **زمان کار و واقعی**
- **یادداشت** برای هر کار

### 🔥 پیگیری عادت‌ها
- **Streak** (زنجیره روزهای متوالی)
- **Longest Streak** (طولانی‌ترین زنجیره)
- **نمای ۷ روز اخیر** با تقویم بصری
- **۱۰ آیکون** و **۱۰ رنگ** برای شخصی‌سازی
- **آرشیو** عادت‌های غیرفعال

### 📝 یادداشت‌ها
- **۷ رنگ** برای دسته‌بندی بصری
- **Pin کردن** یادداشت‌های مهم
- **آرشیو** یادداشت‌ها
- **چک‌لیست** داخل یادداشت
- **تگ‌ها** با فیلتر
- **Grid/List View**
- **جستجو** در عنوان، محتوا و تگ‌ها
- **کپی سریع**

### 🗓️ برنامه‌ریزی هفتگی
- **Time-Blocking** با کلیک روی خانه‌های زمانی
- نمای هفتگی از شنبه تا جمعه
- کشیدن و رها کردن کارها
- نمایش خودکار کارها در ساعت مشخص

### 🍅 تکنیک Pomodoro
- تایمر قابل تنظیم (پیش‌فرض: ۲۵ دقیقه)
- **Auto Start** برای استراحت و شروع مجدد
- **آمار روزانه و کل**
- **صدا و اعلان مرورگر**
- **Widget شناور** در همه صفحات

### 📈 تحلیل‌های پیشرفته
- **نمودار بهره‌وری** هفتگی/ماهانه/سالانه
- **توزیع زمان** بین پروژه‌ها (Pie Chart)
- **پیشرفت پروژه‌ها** (Bar Chart)
- **گزارش‌های Export:**
  - 📊 Excel (چند ورق)
  - 📄 PDF (گرافیکی)
  - 💾 JSON (پشتیبان)
  - 📝 Text (خلاصه)
  - 📑 CSV

### 🏆 سیستم دستاوردها
- **۲۰+ دستاورد** در ۹ دسته
- **۵ سطح کاربری** (مبتدی تا افسانه‌ای)
- **امتیازدهی** برای هر دستاورد
- **اعلان زیبا** هنگام کسب دستاورد

### ⚙️ تنظیمات کامل
- **زبان** - فارسی / English با RTL/LTR
- **ظاهر** - حالت روز/شب/خودکار
- **دسترسی** - کنتراست بالا، متن بزرگ، کاهش انیمیشن
- **پومودورو** - تنظیمات کامل
- **اعلان‌ها** - کنترل کامل
- **داده‌ها** - Export/Import/Reset

### 🔍 جستجوی سراسری
- کلید `/` یا `Ctrl+K`
- جستجو در Tasks, Projects, Notes, Habits
- ناوبری با کیبورد (↑ ↓ Enter Esc)

### 📱 Progressive Web App
- **نصب روی دستگاه** (موبایل و دسکتاپ)
- **کار در حالت آفلاین**
- **Service Worker** با Cache هوشمند
- **Push Notifications** (آماده)

## 🚀 نصب و اجرا

### پیش‌نیازها
- Node.js 18+
- npm یا yarn

### نصب

```bash
# Clone پروژه
git clone https://github.com/USERNAME/smart-planner.git
cd smart-planner

# نصب dependencies
npm install

# تولید آیکون‌های PWA
npm run generate-icons

# اجرا در حالت development
npm run dev

npm run dev              # اجرا در حالت development
npm run build            # ساخت production
npm run preview          # پیش‌نمایش build
npm run generate-icons   # تولید آیکون‌های PWA
npm run lint             # بررسی کد

Development: http://localhost:5173

Preview: http://localhost:4173
